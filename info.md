Technical Jargon -


1. RAG - Retreival Augmnented Generation - retrieved a set of docs from database and uses LLM to generate responses.
RAG is used in chatbots, it retreives responses or snippets of data and then sues AI to shape them into a coherent response for user, perosnlaising it.
Other cases are also customer support, research tools, content creation, anytime u need AI to be gorounded in real time data, we use RAG. basically we uise it for context aware responses.


2.  LangChain - Toolkit helping devs work with LLM more easily. If we want to integrate a LLM with some database, or set of docs we use LangChain. It can be used to build RAG methods. 


3.  LangGraph - It is a specialised library within langchain ecosystem, allowing us to build more structured multi-step processes.
